### 3.5 **(思考)善用AI**

AI 是非常强大的搜索引擎，除了AI已经整理好的信息外，你是否有注意过AI的信息源? AI 是从哪里找到这些信息的？

AI 所提供的信息的质量和准确度很大程度上取决于你所给出的 prompt(指令)的质量，如何写出高质量的 prompt？

AI有时会综合多处信息为你解答，它给出的答案都是对的吗？如果不对，为什么会出现这种现象？（学会辨别 AI 提供信息的质量，时刻保持辩证思维）

或许你已经运用 AI 为你写过代码，发散一下思维，我们是否可以运用 AI 实现一个产品呢？

请记住：**AI 只是工具，人的思考才是主体。**

绝不向没有独立思考盲目使用 AI 获得答案的行为妥协！

参考分享：[【2024移动应用创新赛线上分享第一场：获奖作品《汉字修复师》背后的故事】](https://www.bilibili.com/video/BV1pr421F7pc?vd_source=cbe1c4e8df261127d92cd87498a1ad68)

## 四、正式考核

### 考核第一周（DDL 11月28日）

1. 读书笔记（一）上传 github

2. 熟悉一款思维导图制作工具

   > 推荐：xmind、mindmap、百度脑图

3. **分析产品**

   在下面APP中任选一对进行体验，写出体验文档：

   - 微信读书&网易蜗牛读书

   - 百度地图&高德地图

   - 网易云音乐&酷狗音乐

   产出：产品体验文档

   要求

   - 有功能结构图 & 信息结构图（用思维导图工具制作的）

   - 可以不用按照网上的模板来写，给出自己的思考以及你分析的逻辑（思考内容很重要）

   - 有标题，并且标题的层级要明确

   参考资料

   - [艾瑞咨询行业报告](http://report.iresearch.cn/) [百度指数](http://index.baidu.com/v2/index.html#/?login=1&fromu=http%3A%2F%2Findex.baidu.com%2Fv2%2Fmain%2Findex.html%23%2Fcrowd%2Fqq%3Fwords%3Dqq,%25E5%25BE%25AE%25E4%25BF%25A1) [人人都是产品经理](http://www.woshipm.com/)
   - 书籍《用户体验要素》

### 考核第二周（DDL 12月5日）

1. 读书笔记（二）github

2. **竞品分析**（从产品、数据、用户等方面思考）github

   将上周你体验的两个 APP 进行比较，写出**竞品分析文档**。

   > tips: 想想如果你是某一方的产品经理，想要做得比对方更出色，你会怎么做？
   >
   > （可根据用户分析、需求分析、用户需求定义，功能定义等去设计一个解决方案。）

3. 本周可以先预装 axure（和上述付费软件的推荐同理，挣钱了推荐付费，还是学生阶段考虑破解方案）

### 考核第三周（DDL 12月12日）

1. 读书笔记（三）github
2. 明确什么是原型图？
   1. 画原型图之前需要确定什么信息？

   2. 原型图&设计图之间的差别？


3. 学习Axure，并简单的仿照上面的六个APP（任选一个）做出一个低保真原型图（首页和其他一两个页面即可）

   （可根据用户分析、需求分析、用户需求定义，功能定义等去设计一个解决方案。）

   - 页面包含：文字内容，布局，组件合理的大小

   - 能够进行页面之间的跳转（单击跳转就行）

   对于学习 axure 的一些建议：axure 的话有点像是一个把你对这个产品的一些想法表达给其他人看的工具🔧，特别是交互的动画（页面跳转流程和效果）我觉得目前没有必要花太长时间把它给学精通了,但是一定要会用。

   - 首先需要了解基本的组件和操作

   - 找到几套组件，iOS 的，android 的，微信小程序的，网页的，这几套基本就够了，东西不在多而在精，花太多时间在找组件上也是不对的

   参考资料

   - 不建议花太多时间再复杂的交互动效效果上，**画只是过程，不是目的**
   - 第一，这个前端也许几行代码就搞出来了，你还在这里想老半天，记住你的目的只是表达你的想法呀，没说这就是产品的最终形态；
   - 第二，用axure做出来的原型图最多最多也只算一个中保真原型图，最后又不会拿这玩意给甲方或者最为一个宣传动效，UI不用工作吗？他用AE做出来的动效比你强多了。所以不用太担心，表达清楚就行。
   - 资源一般在“axure中文网”上能找到一些动效的教程，其他的可以关注“UXD公众号”里面会提供一些模版

4. 注册 [蓝湖](https://lanhuapp.com/) 账户，将所画的原型图上传到蓝湖以及 github，并把蓝湖链接发给 mentor，同时 github 考核 repo 的 readme 也附上这个的链接🔗

### 考核第五周（DDL 12月26日）

3. **需求文档**上传 github

   明确需求文档是写给谁看的？需要包含哪些内容？怎么写？

### 最终考核任务

深入思考自身是否存在某些期望达成的想法，亦或是一些独具匠心的奇思妙想，比如你想拥有一个帮助你进行日程记录的小程序...无论是网站、APP还是小程序，如果你已经有了灵感，那就快把它记录下来吧！

1. 目的：锻炼逻辑思维及需求管理能力，激发创新思维，理解用户体验设计，培养PM需要具备的能力。
2. 产出：在考核阶段，需产出产品需求文档（PRD）和原型图。
3. 利用AI尝试实现产品（不作强制要求）

最终考核任务需在考核期间内完成，具体时间自行安排
